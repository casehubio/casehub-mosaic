4. Orchestration Pattern Views

category-specific views for the four orchestration patterns

4a. Supervisor — Hub-and-Spoke Routing

Central supervisor routes tasks to specialist workers via configurable routing strategy

4b. Choreography — Reactive Blackboard

Agents react to shared blackboard state changes — no central controller

4c. Saga — Forward Path + Compensation

Sequential execution with compensating rollback on failure

4d. Decomposition — HTN Task Breakdown

Decomposes complex tasks into specialist sub-tasks via LLM or heuristic strategies

4e. Routing Strategy — Agent Selection Visualization

Routing strategy layouts showing how agents are selected: first-match, round-robin, sequential, select-all, llm-selected, cbr-agent, disposition-aware

5. Perception, Optimisation & Social Pattern Views

grounded views matching real Java YAML types (issue #288)

5a. Summarisation — Multi-Level Pipeline

PipelineDefinition: source event → levels with grouping/summariser → emit events

5b. Observation — World Definition

WorldDefinition: actions, sections, renderer with verbatim/grouped/summarised tier thresholds

5c. Narrative — Decision Pipeline

L0 signals → L1 step summaries → L2 decision narratives

5d. Prompt Optimisation — Pipeline Configuration

PromptOptimisationDefinition: named pipelines with signature, optimiser, safety guardrails

5e. Cognition — Cognitive Module Grid

CognitionDefinition: 13 optional config sections with ON/OFF status and config keys

5f. Memory Hygiene — Retention Scoring

Retention config: threshold and weighted scoring (confidence/recency/scope/trust)

6. Coordination Pipeline — Swim Lane + Graph View

KYC verification pipeline with Lanes/Graph toggle (auto-detects graph for fan-out/fan-in). Coordination views exist alongside but separate from the 4 orchestration pattern views above.

7. Agent Drill-Down — Project View

drill-down from pipeline with breadcrumb, eidos, pattern and steps tabs

Agent Diff — Coordination Level

Shows what changed when agents are added, removed, or modified in a pipeline. New PEP screening agent added, quorum tightened 2/3 → 3/4, risk-assessor receives PEP result.
