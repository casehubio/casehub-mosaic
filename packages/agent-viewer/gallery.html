3f. Coalition — Capability Coverage

3h. Judgment — Governance Gate

4. Orchestration Pattern Views

category-specific views for the four orchestration patterns

4a. Supervisor — Hub-and-Spoke Routing

Central supervisor routes tasks to specialist workers via configurable routing strategy

4b. Choreography — Reactive Blackboard

Agents react to shared blackboard state changes — no central controller

4c. Saga — Forward Path + Compensation

Sequential execution with compensating rollback on failure

4d. Decomposition — HTN Task Breakdown

Decomposes complex tasks into specialist sub-tasks via LLM or heuristic strategies

5. Coordination Pipeline — Swim Lane + Graph View

KYC verification pipeline with Lanes/Graph toggle (auto-detects graph for fan-out/fan-in). Coordination views exist alongside but separate from the 4 orchestration pattern views above.

6. Agent Drill-Down — Project View

drill-down from pipeline with breadcrumb, eidos, pattern and steps tabs

Agent Diff — Coordination Level

Shows what changed when agents are added, removed, or modified in a pipeline. New PEP screening agent added, quorum tightened 2/3 → 3/4, risk-assessor receives PEP result.
